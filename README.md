# TVCast

Windows 노트북의 주 모니터 화면을 같은 Wi-Fi에 연결된 여러 TV의 웹 브라우저로 무선 전송합니다. TV 두 대에 같은 PPT 화면을 띄우려고 만들었습니다.

TV에 앱을 설치하거나 별도 장비를 살 필요가 없고, 웹 브라우저만 있으면 됩니다.

## 사용 방법

Python 3과 Pillow가 필요합니다.

```bash
pip install pillow
```

1. 노트북과 TV를 같은 Wi-Fi나 핫스팟에 연결합니다.
2. `start.bat`을 실행합니다.
3. 창에 표시된 주소(`http://IP:8765/6자리번호`)를 각 TV의 브라우저에 입력합니다.

## 알아 둘 점

- 소리는 전송하지 않습니다.
- 화면이 초당 약 8프레임으로 갱신되므로 슬라이드에는 적합하지만 영상은 끊겨 보입니다.
- 주소 끝의 6자리 번호는 실행할 때마다 바뀝니다. 이 번호를 아는 사람은 같은 네트워크에서 화면을 볼 수 있고, 전송은 암호화되지 않습니다. 공용 네트워크에서는 주의하세요.
- 끊기면 `screencast.py`의 `WIDTH`를 `1280`으로 낮춰 보세요.
